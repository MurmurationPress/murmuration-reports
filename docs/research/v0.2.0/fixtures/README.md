# Synthetic publication fixtures

`publication.md` contains ten standalone SVG specifications, descriptive alternatives, comparison/scorecard tables and an 80-row pagination case. These are new research artifacts, hand-authored with deterministic geometry; they are not Reports-generated outputs and do not establish future schema/renderer support. No production asset is changed.

SVG text names DejaVu Sans with a sans-serif fallback; fonts are not embedded. This establishes self-contained resources, not identical font metrics on every reader. Label/font sizes need final-width review. Error bounds are supplied synthetic bounds and no confidence interval is calculated.

Data: line A=[−.6,−.2,.3,.5], B=[−.4,.1,.2,.7], fixed [−1,1]. Scatter is a visual uncertainty specimen; domain/tick design is pending. Bar primary heights=[100,180,140,220], grouped secondary=half primary, stacked secondary=55 each. Histogram counts=[10,18,14,22] with edges=[0,1,2,3,4]; drawn height is 10 pixels/count. Pie/doughnut A=B=50. Radar A=.7,B=.6,C=.8,D=.5. KPI alternatives give exact units, periods and values. Bar/scatter specimens intentionally leave tick-density/precise numeric-axis mapping to P1 design and cannot qualify a production chart implementation.

Fixtures cover all proposed chart families plus structured comparisons and KPI SVG/Markdown. Additional negative/zero/log-domain, long caption, page-width and reader-specific cases remain required before acceptance; see publishing.md.
