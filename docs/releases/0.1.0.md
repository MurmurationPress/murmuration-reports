# Murmuration Reports v0.1.0

Initial standalone release for persistent dataset charts and state tables in ordinary Obsidian vaults. MWC is not required.

- Reports manager with name search, type/status filters, saved SVG/table previews and navigation.
- Guided creation and source-preserving definition editing, including explicit reconciliation of external edits.
- Explicit single/batch generation with per-report results; no background generation or migration.
- Ownership receipts, validated adoption/repair and recovery copies. Existing schemas, paths and legacy table markers are preserved. Saved outputs display and compile with both plugins disabled.

## Install

Requires **Obsidian desktop 1.13.7+**. Download `main.js`, `manifest.json` and `styles.css` from this release into `<vault>/.obsidian/plugins/murmuration-reports/`, reload Obsidian, and enable Murmuration Reports in Community plugins. Open Reports from the command palette or ribbon. No npm/Node.js, MWC or Codex Press installation is required to use the plugin. SVG PDF exports use the compiler's existing conversion toolchain.

## Known limitations

Mobile is unsupported; Windows CI does not establish Windows live UI qualification. Drafts and outcomes are session-only. Ambiguous YAML, overlapping edits, unreadable declarations and uncertain ownership require explicit repair/reconciliation. Obsidian has no exclusive create, external-sync lock or crash-atomic multi-file transaction: ambiguous/interrupted writes may leave assets, receipts or recovery copies requiring manual inspection. Receipts are unnecessary for viewing or compiling assets.

Validated with 107 automated tests, strict types, production/packaging checks, local acceptance, Ubuntu/Windows CI and synthetic PDF/EPUB/DOCX exports. This release preserves the accepted reporting implementation and dependency versions.
