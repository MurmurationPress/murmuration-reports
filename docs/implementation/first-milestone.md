# First milestone implementation contract

Implements the accepted bounded specification from research merge `c15efbe2f79809fd0139ea14ed69268862a04543`; no chart/scale dependency or lifecycle redesign. Production release metadata stays unchanged; no release is requested.

The schema is `presentation: publication` with optional numeric `y_min`/`y_max` (both or neither) and plain-text `caption` (at most 240 Unicode code points). Only the exact publication value activates new chart fields. Legacy unknown/non-publication presentation and opaque bounds/caption stay ignored/preserved; guided saves reject a newly requested unsupported presentation rather than store ineffective settings.

Publication layout uses a 960-unit canvas, fixed 32-unit ordinary text (8.4pt at 3.5in), 3-unit essential strokes (0.7875pt at 3.5in), stable colour plus solid/circle, dashed/square, dotted/triangle, dash-dot/diamond identities. No runtime DOM/canvas/font measurement, locale or theme. Text wraps at whitespace using a conservative 1.2em-per-code-point bound (1.6em for U+01C4–01CC/U+01F1–01F3 digraphs) for the qualified DejaVu Sans/Liberation Sans fonts. Title, subtitle, axis labels, legends and caption have bounded line counts; unbreakable words, unsupported glyphs or excessive total height block with the field and shortening/restructuring advice. Never shrink text or truncate. Supported text: printable ASCII, Latin U+00A0–024F, the shared DejaVu/Liberation Greek subset, selected shared typographic punctuation and minus/≤/≥. Combining marks, emoji, RTL/CJK and other scripts need separately qualified layout; host font substitution still requires verification. Numeric labels adapt precision to remain distinct; endpoints remain exact. Extremely narrow domains may have fewer representable tick values, never duplicate labels.

Fixed bounds apply after unchanged whole-source numeric/date validation and date/window selection. Out-of-domain selected values block with path/property/value and limits. Publication automatic domains are resolved separately; legacy auto rendering remains byte-identical. Single/constant series receive a finite automatic domain or an actionable diagnostic.

Explicit `comparison: {mode: explicit-pair, current: ..., previous: ...}` selects safe vault-relative `.md` paths inside the declared recursive source subtree. Case/NFC identity uses existing path collision rules: a unique alias resolves to the actual observation, multiple candidates block, same identity cannot form a pair. Previous date must be strictly earlier; optional end equals current date. Source membership/date/finite-value validation remains whole-folder. Missing/renamed/unreadable references never trigger predecessor search. No auto-follow/rewrite on rename. Deltas remain signed two-decimal absolute changes; no percentage convention. Date-labelled headers and escaped source-path comparison text identify the actual pair. Existing receipt/marker and guarded generation/recovery are unchanged.

New manager controls must retain unknown nested fields/comments/body. Toggling publication off stores an inert legacy mode without deleting opaque options. Explicit pairs can be enabled on a previously absent comparison; changing/removing an existing comparison mapping cannot silently destroy unknown fields and requires editing the note when the source-preserving editor cannot represent it safely.

Supported PDF placements: 3.5/4.1/5.5in where local page/container space permits. Publish through Codex Press `394cf109f035194b440e3b37d75de06e49fe074d`; measure actual placement and ≥8pt text/≥0.5pt essential strokes. A smaller fitted width needs another layout and remains outside this milestone. Physical-print, reader/AT, accessible PDF (#144) and broad chart/KPI qualification remain pending in #12. Feature-generated outputs, not hand-authored research specimens, are required for implementation evidence.

Font coverage was checked with Fontconfig `fc-query` for the installed reference/fallback fonts. Conservative advance bounds use 1.2em ordinarily and 1.6em for wide Latin digraphs; no font table/runtime metric dependency is shipped. Substitution or broader text still requires operator sizing/bounds checks.

The source subtree means the actual declared folder, not another physical folder differing only by case. Portable case/NFC aliases of an observation are resolved only within that actual subtree; duplicate candidates anywhere in its portable identity fail closed. Explicit-pair delta overflow is diagnosed rather than serialising Infinity. Existing coordinator status conventions stay intact: validation failures are `failed`, ownership/lifecycle constraints are `blocked`; neither writes a replacement output.
